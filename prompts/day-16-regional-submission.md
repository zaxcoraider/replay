# Day 16 — Regional Superteam + Side-Track Sweep

## Goal

Submit to every relevant side track. This is a distribution day, not a code day.

## Deliverables

1. **Sweep the earn.superteam.fun board.** Filter to Frontier hackathon. List every track whose description plausibly applies. For each:
   - Copy its requirements to a local doc.
   - Verify your project meets them.
   - Prepare a tailored submission (unique writeup per track — copy-paste kills you).
   - Submit.

2. **Regional Superteam track.** Your local region's Frontier sidetrack. Requirements vary; read carefully.

3. **Helius side track submission.** Link the blog post draft from Day 14. Paste the LaserStream integration code snippet. Make the case concretely: "Replay is the best possible showcase of LaserStream — here's why."

4. **Public Goods submission via Colosseum.** In the Colosseum submission form (or via the separate flag — verify this with the hackathon rules), select Public Goods and attach your 200-word writeup.

5. **Ackee / security track if available.** Submit a "proof of exploit via Replay" — take one historical incident (public, post-mortem published), reproduce it in Replay, mutate the state to what it should have been, show the exploit wouldn't have occurred. Write up 500 words.

6. **Social push:**
   - Launch tweet — demo video + one-liner. Tag @heliuslabs @SolanaFndn @SuperteamDAO.
   - Post in #hackathon and #dev-tools channels in every Solana Discord you're in.
   - Post to Reddit r/solana.
   - Send the Helius blog draft to their dev-rel contact (email or Discord DM).

7. **Community discord amplification:**
   - Anchor Discord — dev-tools channel
   - Solana Tech Discord — builders channel
   - OrcaDAO Discord — dev channel (Whirlpool shows up in your demo — they'll care)

## What NOT to do

- No new features.
- No big refactors.
- Minor bug fixes only if they appear during submission testing.

## End-of-day

- Submissions checklist (`docs/07-submission-checklist.md`) — every "Submissions" box checked.
- Social post live.
- Helius contacted.
